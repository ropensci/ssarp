# Package index

## Prepare Occurrence Records

- [`find_land()`](https://docs.ropensci.org/ssarp/reference/find_land.md)
  : Find the name of the land on which the occurrence points were found
- [`find_areas()`](https://docs.ropensci.org/ssarp/reference/find_areas.md)
  : Find areas of land masses.
- [`remove_continents()`](https://docs.ropensci.org/ssarp/reference/remove_continents.md)
  : Remove continents from area dataframe.
- [`find_pam_areas()`](https://docs.ropensci.org/ssarp/reference/find_pam_areas.md)
  : Find areas of islands using a presence-absence matrix (PAM)

## Estimate Speciation Rates

- [`estimate_dr()`](https://docs.ropensci.org/ssarp/reference/estimate_DR.md)
  [`estimate_DR()`](https://docs.ropensci.org/ssarp/reference/estimate_DR.md)
  : Get speciation rates using the DR statistic (Jetz et al. 2012)
- [`estimate_ms()`](https://docs.ropensci.org/ssarp/reference/estimate_MS.md)
  [`estimate_MS()`](https://docs.ropensci.org/ssarp/reference/estimate_MS.md)
  : Get speciation rates following equation 4 in Magallón and Sanderson
  (2001)
- [`estimate_bamm()`](https://docs.ropensci.org/ssarp/reference/estimate_BAMM.md)
  [`estimate_BAMM()`](https://docs.ropensci.org/ssarp/reference/estimate_BAMM.md)
  : Get tip speciation rates from BAMM (Rabosky 2014) analysis

## Create Relationships

- [`create_sar()`](https://docs.ropensci.org/ssarp/reference/create_SAR.md)
  [`create_SAR()`](https://docs.ropensci.org/ssarp/reference/create_SAR.md)
  : Create a species-area relationship (SAR) plot
- [`create_spar()`](https://docs.ropensci.org/ssarp/reference/create_SpAR.md)
  [`create_SpAR()`](https://docs.ropensci.org/ssarp/reference/create_SpAR.md)
  : Create a speciation-area relationship plot (SpAR)
